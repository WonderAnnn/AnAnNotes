# 安安简记 发布与隐私文案（草稿，2026-10-27）

用途：应用商店简介与隐私声明的发布文案草稿。**每一句均可溯源到工程证据**；发布前若有代码变更触及下列事实，须同步修订本文件与文案。本文件不是法律意见，正式发布前建议按目标商店要求做法务审阅。

## 一、应用简介（商店文案草稿）

> 安安简记是一款完全离线的笔记应用：记事、富文本排版、图片插入、本地 OCR 文字识别、PNG/PDF 导出、皮肤与主题个性化。应用不申请联网权限，你的笔记不会被上传到任何服务器。

## 二、隐私声明（正式文案草稿）

### 数据存储边界

- **普通笔记**（文字与图片）保存在应用私有存储内的本地数据库与文件中，依靠 Android 应用沙箱与其他应用隔离；卸载应用即随之清除。**普通笔记没有应用级加密**，设备本身未加密或已解锁状态下，能物理接触设备并具备高级技术能力的人员理论上可以读取。
- **私密模块**是独立加密区：以你的口令经 Argon2id 派生密钥，用 AES-GCM 加密存储。没有口令无法读取私密笔记及其附件。忘记或丢失私密口令将无法恢复私密数据。
- 私密笔记一旦**主动导出、分享或复制到系统剪贴板**，就以明文离开了加密保护边界，请自行注意接收对象与存放位置。

### 联网与权限

- 应用**不申请 `INTERNET` 权限**，不具备联网传输数据的能力（此项由构建流程门禁强制校验，而非口头承诺）。
- 实际申请的系统权限共四项，均为本地后台任务所需：`WAKE_LOCK` 与 `FOREGROUND_SERVICE`（导出/OCR 等后台任务在息屏后继续完成）、`RECEIVE_BOOT_COMPLETED`（开机后恢复被中断的后台任务排期）、`ACCESS_NETWORK_STATE`（仅查询设备网络状态以优化任务排期，不能传输任何数据）。
- 不申请通讯录、定位、相机、录音、短信、通话记录等任何敏感权限；不读取设备上其他应用的任何数据。

### OCR

- OCR 引擎与语言模型随安装包提供，在设备本地运行，识别过程与结果不上传、不联网。

### 导出与备份

- PNG/PDF 导出通过系统文件选择器（SAF）写入你指定的目录，导出的文件是普通未加密文件。
- 私密数据备份包以备份口令加密；请把口令与备份分开存放。

### 边界声明

- 以上加密实现与安全声明**未经第三方独立审计**，我们不使用"军工级""绝对安全"等表述。
- 合成图像上的 OCR 表现不能代表所有真实照片或聊天截图的识别效果，我们不对识别准确率作具体承诺。

## 三、文案红线（依据交接指南，任何对外材料不得出现）

1. 不得宣传"所有笔记均加密"——普通笔记没有应用级加密。
2. 不得宣传或暗示"绝对安全/军工级/不可破解"。
3. 不得承诺 OCR"高准确率"或具体百分比——真实素材基准尚未建立。
4. 不得声称"经过安全审计"——第三方审计尚未执行。
5. 不得暗示数据"云端同步/备份"——应用无联网能力。
