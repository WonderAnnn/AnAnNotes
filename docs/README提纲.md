## 3. 核心差异功能（每节 = 一句话卖点 + 截图 + 细节点）

### 3.1 物理级离线：连联网权限都没有
- **卖点草稿**：不是"支持离线"，是**应用根本无法联网**——权限清单中没有 INTERNET，且由构建流程门禁强制校验，不是口头承诺。
- **细节点**：无账号、无同步、无推送、无统计上报；OCR 模型随安装包内置。
- **截图**：`01-permissions.png`（系统"应用信息 → 权限"页，四项权限全景：WAKE_LOCK / ACCESS_NETWORK_STATE / RECEIVE_BOOT_COMPLETED / FOREGROUND_SERVICE，配一行注释说明每项用途）
- **捕获方式**：auto（模拟器系统设置页）

### 3.2 私密模块：真加密，不是应用锁
- **卖点草稿**：独立加密区，口令经 Argon2id 派生密钥后 AES-GCM 加密存储，图片附件同样加密；私密导出还需再次认证。
- **细节点**（诚实边界必须写）：忘记口令无法恢复；私密内容一旦导出/分享/复制到剪贴板，即离开加密边界。
- **截图**（4 张，深色为主）：
  | 编号 | 画面 | 前置状态 |
  |---|---|---|
  | 02 | 首页私密入口 | 深色 + 月下星河皮肤 |
  | 03 | 私密口令解锁页 | 已初始化演示口令 |
  | 04 | 私密笔记列表 | 2 条演示私密笔记 |
  | 05 | 私密导出重新认证提示 | 触发导出流程 |
- **捕获方式**：auto

### 3.3 本地 OCR：图片文字识别不联网
- **卖点草稿**：截图、照片放进笔记即可识别文字，全程设备本地完成。
- **细节点**：如实声明——演示用样本为合成/清晰文本，不能代表所有真实照片与聊天截图的识别准确率。
- **截图**（3 张）：

  | 08 | 飞行模式下的识别成功 | 系统飞行模式开启（标志性画面）|
- **捕获方式**：auto（飞行模式用 `cmd connectivity airplane-mode enable` 或 `svc wifi/data disable`）

### 3.4 每条笔记都有自己的皮肤（11 款）
- **卖点草稿**：不是全局换肤，是**每条笔记独立皮肤**；已有笔记永远保留自己的皮肤，新笔记可用默认皮肤设置。
- **细节点**：皮肤名以应用内实际目录为准（捕获时核对 `NoteSkinCatalog` 全部 11 款名称）。
- **截图**（4 张）：

  | 12 | 山茶/银杏（或纸笺散花）特写 | 同上 |
- **捕获方式**：auto（09 为合成图）

### 3.5 A4 600 DPI 高清导出（PNG / PDF / 社交长图）
- **卖点草稿**：打印级导出。PNG/PDF 按 A4 600 DPI 输出；自研流式编码器逐行写盘，超大导出不占爆内存，超 128 MiB 安全上限会明确提示改用分页。
- **细节点**：导出目录由你通过系统文件选择器自选（SAF）；导出历史可回溯。

## 7. FAQ（草稿）

- **忘记私密口令怎么办？** 无法找回，这是加密设计的必然（口令不存任何副本）。
- **换手机怎么迁移？** 备份 → 拷贝备份包 → 新手机恢复（私密部分需备份口令）。
- **为什么没有云同步/账号？** 应用没有联网权限，这是隐私模型的地基。
- **会收费吗？** 无账号无订阅（当前版本的既定形态）。
