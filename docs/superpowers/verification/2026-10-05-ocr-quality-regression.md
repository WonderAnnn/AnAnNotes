# OCR 质量回归验证（2026-10-05）

## 目的与范围

在不更换 OCR 模型、不增加联网能力或权限的前提下，扩展离线 OCR 的确定性回归样本，并实现小角度倾斜检测与保守纠偏候选。另以同一批合成页面比较 Tesseract 页面分割模式，决定是否调整生产默认模式。既有 EXIF、低对比度、压缩、小字号、中英文数字混排、状态栏噪声和私密 OCR 内存处理回归一并复测。

## 验证环境

- 模拟器：`AnAn_API36_Pixel6(AVD) - 16`。
- OCR：本地 Tesseract 5.5.1（Tesseract4Android 4.9.0），中文简体与英文语言包。
- 图像合成、JPEG 压缩和 EXIF 注入均在测试中本地完成，不访问网络。

## 新增与扩展的回归场景

确定性本地合成语料位于 `app/src/androidTest/java/com/anan/anannotes/ocr/OcrSyntheticCorpus.kt`，记录 CER、文本行数、状态栏禁词和识别耗时：

| 页面 | CER 上限 | API 36 实测 CER | 实测行数 |
| --- | ---: | ---: | ---: |
| 中英文、数字混排正文 | 8% | 0% | 4 |
| 小字号低对比正文 | 12% | 0% | 4 |
| 含模拟状态栏的稀疏截图 | 12% | 2.70% | 4 |
| 双栏页面 | 20% | 18.33% | 7 |

识别耗时单次约 0.48–0.90 秒，仅作这台模拟器上的参考，不作为性能保证。仪器测试不得记录识别出的正文内容，只输出样本 ID 和质量指标。

另新增 `OcrDeskewEstimator`：从不超过 640 px 的灰度缩略图做 Otsu 二值化和行投影搜索，范围为 ±7°、步长 0.5°；低于最小角度或投影增益阈值时不纠偏。启用纠偏时同时识别原图和纠偏候选，仅当已有候选选择器确认文字覆盖、行数、文本相似度与置信度条件满足时才采用；否则保留原图。候选行的位置按各自图像高度归一化比较。原图和临时 Bitmap 在 `finally` 中回收，图片字节不写入临时明文文件。

纠偏回归使用低对比、小字号文本旋转 6° 并以 JPEG quality 28 压缩：纠偏阶段被触发，基线与最终 CER 均为 3.08%，文本行数为 4。结果表明该样本未退化，但没有证明识别率提升。

页面分割基准位于 `TesseractPageSegmentationBenchmarkTest.kt`，对四种模式使用完全相同的合成语料及正文行过滤：

| 模式 | 平均 CER | 达到行数下限的布局 | 耗时 | 状态栏噪声命中 |
| --- | ---: | ---: | ---: | ---: |
| AUTO | 5.26% | 4/4 | 876 ms | 0 |
| SINGLE_BLOCK | 16.48% | 3/4 | 769 ms | 0 |
| SINGLE_COLUMN | 16.09% | 3/4 | 843 ms | 0 |
| SPARSE_TEXT | 19.94% | 4/4 | 1125 ms | 0 |

本轮因此保留生产 `PSM_AUTO`：它在相同语料中 CER 最低且所有布局均达到行数下限；虽然不是最快模式，但更适合混合与多栏页面。

既有集成场景仍位于 `app/src/androidTest/java/com/anan/anannotes/ocr/TesseractOcrEngineIntegrationTest.kt`：

1. 低对比度、JPEG quality 48 的中英文数字混排样本：字符错误率（CER）不高于 12%，识别行数为 4–7。
2. 720×322、小字号、低对比度、JPEG quality 28 样本：CER 不高于 12%，识别行数为 4–7。
3. 480×215、极小字号、低对比度、JPEG quality 24 样本：CER 不高于 12%，识别行数为 4–7。
4. EXIF orientation=8 的旋转 JPEG：验证图像解码先按方向纠正为 1700×760，再执行离线 OCR；CER 不高于 8%，识别行数为 4–7。
5. 清晰合成文本：除换行、回车和制表符外，不应出现意外 ASCII 控制字符。
6. 保留既有私密 OCR 集成回归：验证识别流程仅在内存中处理解密明文，并清除明文缓冲区。

## 结论与限制

新增合成样本达到预设门槛；倾斜候选在这一组样本中未劣于原图；页面分割对照支持继续使用 `PSM_AUTO`。这些结果仅支持当前处理路径和回归基线，不代表真实照片识别率已经提升，也没有证明倾斜纠正会改善真实素材。

这些合成图片不能充分模拟相机噪声、透视、反光、复杂背景、微信/QQ 二次压缩和真实中文排版；因此真实场景的 OCR 准确率仍未验收。若要针对实际误识别继续调参，仍需少量已脱敏、允许本地测试的失败图片及对应正确文本；在取得样本前不应凭空调整阈值或图像处理，以免损害已通过场景。
