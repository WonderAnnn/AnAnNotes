# 安安简记（AnAn Notes）V1 产品与界面设计

- 状态：产品设计已批准，V1 实现进行中；本文件冻结产品规则，实施进度以实现计划为准
- 日期：2026-09-26
- 最近更新：2026-09-27
- 总体技术设计：[V1 总体技术设计](2026-09-27-anan-notes-v1-technical-design.md)
- 平台：Android 手机，竖屏优先
- 最低系统：Android 10（API 29）

## 1. 产品目标

安安简记是一款轻量、易上手、以本地隐私为先的 Android 笔记应用。首版重点是快速记录、方便查找、舒适编辑、可靠导出，以及由用户掌控的加密备份。应用不要求账号，不上传笔记，不申请网络权限。

用户希望它接近手机自带笔记的学习成本，同时提供更灵活的笔记皮肤、图片块、全文搜索和高质量导出。初始参考截图仅用于理解常见笔记首页和编辑页结构；其中的品牌、具体文字和未讨论功能不构成安安简记需求。

## 2. 产品原则

1. **快速记录**：点击首页加号后直接进入文字编辑页；每条笔记独立保存；空白笔记离开时不保存。
2. **本地优先**：笔记和附件默认只保存在设备上，不强制登录、不联网、不上传。
3. **用户可控**：图片、导入、导出、备份和恢复由用户通过系统选择器发起。
4. **清晰而克制**：界面跟随系统字体缩放，留白充足，常用操作容易发现。
5. **导出忠实**：PDF 和 PNG 尽量呈现笔记当前皮肤、字体、图片和排版；原图用于正式导出。
6. **私密区隔离**：加密笔记在输入密码前不泄露标题、摘要、图片、数量或待办内容。

## 3. V1 范围

### 3.1 包含

- 普通笔记的新建、编辑、自动保存、文件夹管理、搜索、置顶、排序和回收站
- 混合编辑器、五种内置皮肤、图片内容块、字号和行距设置
- 本地离线 OCR，识别结果可编辑并可搜索
- 独立加密笔记模块及恢复密钥
- 笔记内待办和独立待办页
- PDF、PNG、TXT、Markdown 导出
- 私密笔记验证后导出，以及本地导出记录
- 系统分享导入、TXT/Markdown/图片导入
- 手动加密备份、合并恢复和冲突处理
- 一页式首次启动隐私说明

### 3.2 暂不包含

- 云同步、账号体系、在线服务、远程 OCR
- 待办通知、日历、复杂任务管理
- 多级文件夹、多文件夹归属
- 自定义壁纸皮肤、手写识别、表格/公式 OCR
- 图片滤镜、画布自由拖放、文字环绕
- 编辑历史版本、批量加密、批量换肤
- 平板、折叠屏专属布局；首版以手机竖屏为主

## 4. 信息架构

```text
安安简记
├─ 笔记
│  ├─ 全部 / 一级文件夹 / 未分类
│  ├─ 搜索结果
│  ├─ 笔记编辑器
│  ├─ 加密笔记入口 → 密码解锁 → 私密笔记列表与编辑器
│  ├─ 回收站
│  └─ 设置
│     ├─ 外观：字体与显示、默认皮肤、主题模式
│     ├─ 导入与导出：导入、导出记录、导出位置
│     ├─ 隐私与安全：加密笔记、密码与恢复密钥、备份恢复
│     └─ 数据与存储：回收站、缓存清理、存储占用
└─ 待办
   ├─ 未完成列表
   └─ 显示已完成
```

底部导航只包含“笔记”和“待办”。加密模块沿用相同的导航框架，但其中的笔记与待办必须限制在加密模块内部，不能出现在普通笔记搜索或普通待办列表中。

## 5. 视觉系统

### 5.1 普通笔记

- 首页基础方向：用户选择的 **A「极简留白」**。
- 编辑器融合留白和专注写作：顶部轻量操作，正文区域宽松，键盘上方提供格式工具。
- 默认主操作色：深石墨色；辅助表面使用白色和冷灰；选中、完成和反馈等状态只使用少量低饱和蓝灰；危险操作使用石墨灰分级。蓝灰不得作为大面积页面背景、整块卡片或普通主按钮底色。
- **不使用黄色作为全局强调色**。此前预览里的黄色属于临时草案，不是已确定的设计要求。
- 按钮统一：主要按钮为深石墨实底，次要按钮为白底石墨描边，低强调操作为灰蓝文字，危险操作为灰度描边或深石墨文字。蓝灰只允许用于小型进度条、选中标记和状态文字。统一按钮高度、圆角、内边距、禁用和按压状态。
- 深色模式是内置主题之一，并根据主题调整文字、分隔线、卡片和状态色。

### 5.2 加密模块

- 采用用户选择的 **「无图标文字风」**：文字、间距和细分隔线表达私密感，不用大锁头、钥匙插画或黄色圆形底图。
- 以石墨、冷灰和极少量深蓝灰状态色构成；不使用大面积蓝色背景；按钮仍遵循全局按钮规范。
- 未解锁的入口只显示“加密笔记 / 独立加密空间”等中性信息，不显示内容数量或摘要。
- 系统最近任务预览在私密模块解锁期间应隐藏敏感内容；离开模块或应用进入后台时锁定模块。此行为在界面流程讨论中已确认。

### 5.3 内置皮肤

首版内置六种：

1. 极简白
2. 米白纸张
3. 薄荷清新
4. 深海蓝
5. 夜墨黑
6. 纸笺散花（浅樱粉底与低对比度五瓣樱花纹样）

每条笔记保存自己的皮肤。设置中的全局默认皮肤只影响新建笔记，不覆盖已有笔记。编辑页顶部调色板按钮打开底部面板：皮肤卡片横向滑动，下方显示当前笔记的实时预览；点击即应用并自动保存。“纸笺散花”由应用本地绘制，不加载网络素材，并在普通/私密编辑、皮肤预览、PDF 与 PNG 中保持一致。自定义壁纸皮肤放到后续版本。

## 6. 核心界面与交互

### 6.1 首次启动与首页

- 首次启动显示一页隐私说明：不强制登录、不联网、笔记和图片保存在本机、OCR 在本地运行、备份由用户手动控制。点击“开始使用”进入首页；设置中可再次查看。
- 空首页显示“还没有笔记 / 点击右下角 + 开始记录”，保留留白，不创建示例笔记。
- 首页包含标题、搜索栏、横向文件夹栏、排序/布局设置入口、自适应笔记卡片、独立加密笔记入口和底部导航。
- 文件夹栏位于搜索栏下方。系统筛选入口在前，用户文件夹随后；横向滑动浏览。
- 文件夹模型为一级文件夹 + 系统“未分类”。每条普通笔记只归属一个文件夹。删除文件夹时，将其中笔记移至“未分类”，不删除笔记。
- 在文件夹内点击加号，新笔记归入当前文件夹；在“全部”视图点击加号，归入“未分类”。
- 自适应卡片默认双列；窄屏或较大系统字体下自动转为单列。卡片显示标题、时间、少量正文摘要和第一张图片缩略图，整体文字优先。
- 置顶笔记排在最前；其余笔记默认按最近编辑时间排序。用户可切换为创建时间排序，切换带平滑位置动画。每个文件夹记住自己的排序方式。
- 排序按钮位于文件夹标题区域右侧，打开底部面板，面板包含排序方式和卡片布局说明。V1 不提供手动单列/双列切换，也不为每个文件夹保存独立布局；系统根据屏幕宽度、系统字体大小和卡片最小可读宽度自动决定双列或单列。
- 点击卡片打开笔记；长按进入多选。批量操作包括移动文件夹、置顶/取消置顶、导出、删除。编辑页也提供单条笔记更多操作。
- 多选状态顶部显示已选择数量，底部操作栏只提供“移动文件夹”“置顶/取消置顶”“导出”“删除”。移动文件夹使用底部面板选择目标文件夹；批量删除只将笔记移入回收站，不直接永久删除，并显示 30 天内可恢复的说明。

### 6.2 搜索

- 输入即搜索，停止输入约 300ms 后更新结果。
- 搜索标题、正文、引用、待办和 OCR 生成的文字块。
- 支持“全部笔记”和“当前文件夹”范围。
- 搜索结果显示匹配片段；匹配文字加粗，并使用当前皮肤的可读强调色。
- 普通搜索不包含加密模块内容。进入并解锁后，私密模块可以在自身范围内搜索。

### 6.3 新建、编辑和自动保存

- 点击加号直接打开文字编辑器，不先显示创建菜单。
- 正文第一行默认作为标题，可单独修改；标题为空时显示“无标题笔记”。
- 自动提取标题后，第一行仍保留在正文中；用户修改标题不会改写正文内容。
- 空白笔记离开时不保存；输入文字、插入图片、添加待办或修改标题后才创建正式笔记。
- 内容停止变化后实时自动保存；编辑页显示保存状态。应用异常退出后，下次启动提示恢复临时草稿，用户可恢复或丢弃。正常退出不重复生成草稿。
- 编辑器为混合编辑器：普通文字编辑与图片、待办、引用、分割线等独立内容块共存。
- 基础格式工具在键盘上方，包括加粗、标题、待办、图片；“更多”展开斜体、删除线、引用、分割线等。键盘收起时工具栏隐藏。
- 系统字体大小影响应用界面；设置页提供“字体与显示”实时预览，可调整全局默认正文字号和行距。编辑页点击 `Aa` 打开底部面板，可在“全局默认”和“仅本条笔记”之间选择并调整当前笔记。单条笔记可覆盖字号和行距；全局修改不强制覆盖已单独调整的笔记。首版使用系统字体，不内置第三方字体文件。

### 6.4 图片与 OCR

- 使用 Android 系统照片选择器导入图片，不申请广泛相册权限。
- 图片为独立内容块，保持原始比例，默认居中；不支持自由拖动变形。
- 点击图片可调宽度百分比，默认 100%，支持数字输入和滑动调节；可锁定比例、左/中/右对齐、适应内容宽度、裁剪或删除。高度按原图比例计算。
- 存储原图，并生成首页/编辑预览缓存。缓存可自动清理并重新生成；原图不会因缓存清理而删除。正式导出使用原图。
- 选图后提供三种处理方式：仅插入图片、插入图片并识别文字、只识别文字不保留图片。
- OCR 模型内置、离线运行，V1 内置清晰印刷体中文和英文识别，并默认自动处理中文、英文和数字混排；用户不需要在每次识别前选择语言。手写、表格和公式识别不列入首版承诺。
- “插入图片并识别文字”时，图片后生成独立、可编辑的 OCR 文字块；“只识别文字”只保存文字。OCR 结果尽量保留原始换行，并可参与搜索。
- “插入图片并识别文字”采用异步处理：原图先立即插入，图片下方固定显示蓝灰色横向进度条、文案“正在识别”和动态进度百分比；不遮挡原图，用户可以继续编辑。进度由预处理、识别和文字整理阶段估算，不承诺逐像素精确。
- OCR 成功后自动替换状态占位并生成可折叠、可编辑的文字块；短文本默认展开，较长文本默认只展示少量预览文字和“展开全文”，展开后可以直接编辑。识别中的占位文字不参与搜索，折叠状态不影响全文搜索和导出。失败时保留原图，显示失败原因和“重试识别”操作；应用异常退出后保留待处理状态，不丢失原图。
- 用户可以取消正在进行的 OCR；取消后只保留原图，不生成不完整文字块，状态显示“已取消识别”，并提供“重新识别”操作。
- OCR 失败时不丢失用户选择保留的原图，并给出可理解的失败提示。具体模型、许可证、安装包体积和批量识别处理策略需在技术方案阶段确认。

### 6.5 待办

- 底部第二个页面为“待办”，集中展示普通笔记中的全部未完成待办。
- 按最近修改时间排序；每项显示内容、来源笔记标题和文件夹。点击后跳转到原笔记对应位置。
- 勾选后从默认待办列表隐藏，但仍保留在笔记中；页面提供“显示已完成”开关，可取消勾选恢复。
- 笔记内完成项显示勾选框、删除线和淡化文字，状态色随皮肤适配；整体完成状态采用低饱和蓝色，不用黄色。
- V1 不提供截止日期、提醒或通知权限。
- 加密笔记待办仅在加密模块内可见，不混入普通待办页。

### 6.6 加密笔记

- 普通首页提供独立的“加密笔记”文字卡片作为入口。点击后进入模块密码页；首次使用时创建模块密码并设置恢复密钥，之后输入密码解锁。
- 设置中的“隐私与安全”页面采用两个分区： “私密笔记”包含加密笔记、密码与恢复密钥；“备份与恢复”包含加密备份、恢复和隐私说明。页面不使用额外宣传副标题或无关标语。
- 密码页提供“使用恢复密钥”。不使用全应用锁，不显示生物识别承诺。
- 解锁后进入独立笔记列表和编辑器；退出模块或应用进入后台时重新锁定。
- 未解锁状态下，标题、正文、图片缩略图、数量、搜索结果、待办和最近任务预览均不得泄露。
- 使用随机字符恢复密钥，创建时显示一次，用户可以复制、手抄或通过系统选择器保存。应用不保存可直接取回的明文恢复密钥。
- 更换恢复密钥需验证当前密码；生成新密钥后要求用户确认已保存，确认后旧密钥失效。
- 忘记密码且没有有效恢复密钥时，应用无法恢复加密内容；必须在设置恢复密钥时明确告知。
- 私密笔记支持导出，但导出前必须重新输入当前私密模块密码进行验证；恢复密钥仅用于恢复或重置流程，不作为日常导出的常规凭证。
- 私密笔记导出的 PDF、PNG、TXT 和 Markdown 默认是可被用户读取的普通文件；导出前必须明确提示“导出文件不再受安安简记私密模块保护”。需要继续加密保存时，应使用加密备份格式。
- V1 不为私密 PDF、PNG、TXT 或 Markdown 单独实现文件级密码保护；私密导出的普通文件与加密备份明确区分。
- 私密笔记、附件和搜索索引均需加密。V1 采用 Argon2id + AES-256-GCM；每个私密模块使用一个随机数据密钥，密码派生的保护密钥和恢复密钥派生的保护密钥分别封装该数据密钥，二者均可独立解锁。修改密码时只重新封装数据密钥，不重新加密全部内容。密钥派生参数、密钥封装、恢复流程、内存清理和加密格式仍须在实现前经安全设计审查。

### 6.7 回收站

- 删除的普通笔记进入回收站，保留 30 天；用户可恢复或立即永久删除；到期自动清理。
- 恢复保留原文件夹、皮肤、图片、内容和待办状态。
- 加密笔记回收站需先解锁后查看；其中的数据继续加密保护。
- 删除文件夹不会删除笔记；这些笔记转入“未分类”。

### 6.8 导入

- 支持从其他应用通过 Android 系统分享文字、图片和文件生成笔记；QQ、微信等已安装并提供系统分享能力的应用可以直接分享给安安简记。安安简记不登录 QQ/微信、不读取聊天记录，只接收用户主动分享的内容。
- 支持通过系统文件选择器导入 TXT、Markdown 和图片；导入后自动创建笔记，可指定文件夹。
- 首版不承诺小米笔记专用迁移格式或完整保留所有外部 Markdown 扩展。
- 小米笔记迁移、批量文件夹导入和更广泛的 Markdown 附件相对路径兼容不纳入 V1；后续版本另行设计。

### 6.9 导出

导出菜单提供：

- PDF
- PNG（分页，600 DPI）
- PNG（长图）
- PNG（朋友圈方图，1080 × 1080）
- PNG（朋友圈竖图，1080 × 1350）
- TXT
- Markdown

规则：

- 选择格式后直接导出，不强制打开预览；使用笔记当前皮肤、字体、图片和排版。
- PDF 默认使用 A4 页面规格；首版不提供 A5/B5 等额外页面规格，后续根据使用情况扩展。
- PNG 600 DPI 用于高质量分页/打印场景；社交媒体尺寸按固定像素输出，不把 600 DPI 当作社交图片质量开关。
- PDF 以矢量文字排版为优先，图片使用原图并按页面布局缩放。原始图片分辨率不足时，不承诺放大后仍清晰。
- 默认文件名：`文件夹_标题_YYYY-MM-DD.ext`。空文件夹名省略，空标题使用“无标题笔记”；非法文件名字符安全替换。
- 首次导出由用户选择保存位置，之后记住位置；设置中可更换。导出的文件位于用户可访问的共享位置，卸载应用后仍保留。
- PNG 应注册到 Android 媒体库，便于相册发现；普通文档通过 Android 系统文件选择器保存，便于文件管理器发现。图片默认进入共享 Pictures/AnAn Notes/Exports，PDF、TXT 和 Markdown 使用用户选择的目录。
- 成功提示短暂显示已导出文件名和保存位置后自动消退。失败提示显示稳定错误代码、原因和可执行建议，短暂消退；用户点开可查看详情或重试。建议成功约 3–4 秒、失败约 6–8 秒，最终时长待界面验证。
- 建议错误代码：`AN-EXP-001` 渲染失败；`AN-EXP-002` 空间不足；`AN-EXP-003` 保存位置不可写或失效；`AN-EXP-004` 图片读取失败。用户主动取消属于正常结束，不显示为失败。
- 导出成功/失败反馈、导出按钮和文件夹选择按钮遵循统一按钮规范；成功和失败均使用蓝灰/石墨灰信息层级，不使用鲜红色。
- Markdown 中图片以相对资源方式交付；首版打包为 ZIP，内含 Markdown 文件和 `images` 目录。
- 应用提供本地导出记录，入口固定为“设置 → 导入与导出 → 导出记录”。记录格式、时间、文件名、保存位置和成功/失败状态，不保存正文、OCR 文本或图片副本。普通记录可在设置中查看和清除；私密导出记录仅在解锁私密模块后显示并随私密数据加密保存。普通和私密记录分别最多保留最近 100 条，超过后自动清理最旧记录。
- 点击导出记录时，文件存在则直接调用系统应用打开；如果文件已被移动或删除，显示文件不可用状态，但不删除原笔记和导出记录。
- 普通导出记录页面不得显示私密导出记录的存在、数量、格式、文件名或状态；私密记录只能在解锁私密模块后进入私密范围查看。清空导出记录只删除记录元数据，不删除已经导出的文件；文件不可用时允许使用当前笔记重新导出。

### 6.10 加密备份与恢复

- 用户手动触发备份；输入备份密码；通过系统文件选择器选择位置。
- 使用 Argon2id + AES-256-GCM；大型附件采用分块加密。备份不覆盖旧文件，自动按时间命名，例如 `AnAnNotes_2026-09-26_1430.ananbackup`。
- 备份文件可跨设备恢复；设备本地密钥不作为备份解密的唯一条件。
- 默认合并恢复，当前数据不删除。恢复前展示新增笔记、图片、文件夹等数量。
- 笔记使用稳定唯一 ID 去重。检测到当前版本和备份版本均有修改时，逐条显示版本信息，由用户选择保留当前、使用备份或保留两个版本。
- 私密模块数据仍以加密形式进入备份；恢复到私密区前需要相应凭证。不得将私密内容解密后写入普通笔记区。

### 6.11 数据与存储

- 设置中的“数据与存储”显示笔记正文、原图、预览缓存和导出文件的本地占用概览。
- 预览缓存只包含首页卡片和编辑器预览所需的缩略图/中间结果；清理缓存不会删除笔记正文、原图、OCR 文字或已导出的文件。清理后在需要时重新生成。
- 回收站和导出位置从数据与存储页面进入；PNG 图片使用共享 Pictures/AnAn Notes/Exports，PDF、TXT 和 Markdown 使用用户选择的位置。
- 存储空间不足时，不修改原笔记，显示错误码 `AN-EXP-002` 和“可用空间不足，请清理设备空间后重试”，提供查看存储和取消操作。

### 6.12 安装包与导出资源约束

- V1 发布安装包目标控制在 300 MB 以内；笔记正文、原图、导出文件和缓存不计入安装包体积，但会占用用户设备存储。
- 应用代码、Compose/Room/导出组件和基础皮肤应尽量控制在较小体积；离线 OCR 模型必须在技术选型阶段进行体积、许可证和准确率评估。
- A4 600 DPI PNG 按页渲染和写入，不能一次性把整本多页文档全部加载到内存；需要采用逐页渲染、临时文件和失败清理，避免大图导致闪退。
- V1 使用一个随安装包内置的中英混合 OCR 模型，运行时按需加载，不依赖联网下载；模型选择必须以识别效果、许可证和总安装包不超过 300 MB 为硬约束。

## 7. 权限与数据边界

- Manifest 不声明 `INTERNET`，不申请通讯录、电话、短信、定位、通知或广泛媒体读取权限。
- 图片选择使用 Android Photo Picker；文件导入/导出/备份使用 Storage Access Framework。通过用户授权的 URI 操作，不请求“访问所有文件”。
- 使用的 OCR、加密和导出依赖不得引入联网行为；构建后检查合并 Manifest，确认没有依赖意外加入网络权限。
- 普通笔记存储在应用私有空间；用户导出的文件和备份存储在用户选择的共享空间。
- 普通笔记移入 30 天回收站后仍保留原图及其引用，以保证恢复完整；可清理可重建的预览缓存。永久删除或到期清理时，仅删除不再被其他内容块引用的原图及对应缓存。单独清理预览缓存不影响原图。
- 错误日志不得记录正文、标题、OCR 文本、恢复密钥或密码。V1 不向外部服务发送诊断数据。

## 8. 技术方向

V1 技术方向已确定为 Kotlin、Jetpack Compose、Material 3、Room 和 Kotlin Coroutines/Flow，最低 API 29；图片使用 Android Photo Picker，文件导入/导出使用 Storage Access Framework，分享导入使用 Android Sharesheet。实现计划记录依赖版本和工程结构。

建议分层：

```text
Compose UI
  ↓ 用户操作与界面状态
ViewModel / Use cases
  ↓ 业务规则
Repository
  ├─ Room：每条笔记独立记录，以及文件夹、待办、排序配置
  ├─ 私密存储：加密笔记、附件和搜索索引
  ├─ 文件服务：原图、预览缓存、导入导出
  ├─ OCR 服务：离线识别
  └─ 加密备份服务：加密封装、合并恢复、冲突处理
```

数据库与普通笔记仓库已进入实现；OCR 模型及许可证、图片/PDF 渲染实现、私密模块密钥管理和 Argon2id 参数仍需按实现计划完成技术验证。所有依赖必须离线可用，并在最终 Manifest、依赖许可证和安装包体积上做核验。不得把方案草案或预览稿当成已交付功能。

## 9. 关键状态与错误处理

- 自动保存失败：保留编辑内容，持续显示未保存状态并重试；不得静默丢弃。
- 草稿恢复：提示恢复/丢弃；丢弃仅清理草稿，不删除已保存笔记。
- OCR 失败：保留用户选择保留的原图，显示失败原因；允许重试或删除 OCR 块。
- 图片 URI 失效：指出图片无法读取；其余笔记内容仍可编辑和导出（跳过图片需明确告知）。
- 导出失败：稳定错误码 + 本地原因 + 下一步操作；临时文件清理，不修改原笔记。
- 备份恢复失败：原有数据保持不变；在验证备份完整性后再应用导入，避免半恢复状态。
- 私密模块认证失败：不泄露笔记是否存在；限制连续尝试的具体策略在安全设计阶段确定。

## 10. 验收标准

V1 设计和实现至少应满足以下可观察结果：

1. 离线启动、编辑、搜索、待办、OCR、导入和导出可工作；应用不要求账号。
2. Manifest 无网络权限，权限申请只由用户发起的系统选择器授权产生。
3. 新建空白笔记不落库；有内容后自动保存；异常后可恢复草稿。
4. 笔记卡片和搜索高亮遵循当前主题，窄屏/大字体时卡片转单列且内容不截断关键操作。
5. 图片保持原比例，百分比尺寸调整结果可见；清缓存不删除原图。
6. 私密信息在未解锁状态、普通搜索、普通待办和最近任务预览中不可见。
7. PNG 朋友圈预设输出精确像素尺寸；分页 PNG 输出 600 DPI 元数据/布局；PDF 放大文字清晰；原图不被低质量预览替代。
8. 文件保存在用户可访问的位置，PNG 可被系统媒体库发现；成功提示展示文件名和位置，失败提示展示代码和原因。
9. 备份文件通过密码加密，恢复前展示摘要；合并恢复不覆盖未冲突数据，冲突按用户选择处理。
10. 回收站 30 天规则、恢复内容完整性和加密回收站访问门槛符合本设计。

## 11. 已冻结的产品决策与技术验证项

产品层面的主要选择已经完成；以下内容用于区分已冻结的产品规则和仍需通过工程验证的技术细节。

以下项目已由当前讨论确定，不再作为产品选择题：A4 PDF、首行保留在正文、私密导出需当前模块密码验证、提供本地导出记录、Markdown 采用 ZIP、安装包目标不超过 300 MB、内置中文与英文离线 OCR。

仍待技术方案和实际测试确认的项目：

1. **本地 OCR 模型的具体实现**：内置中英混合模型和按需加载已确定；模型许可证、识别效果、安装包体积和批量处理限制仍需通过实际构建与设备测试确认。
2. **加密待办导航**：产品规则已确定：私密待办只在解锁后的私密模块内部显示，不混入普通底部“待办”页，不显示私密任务数量或摘要；页面细节在实现时按同一隐私视觉规范落地。
3. **首页布局**：已确定完全自适应；仍需通过不同屏幕宽度、横向空间和大字体设置进行实际验收。
4. **私密模块本地密钥实现细节**：总体方案已确定为一个数据密钥由密码和恢复密钥分别保护。实现计划中的 Argon2id 参数目前只是待安全审查的候选值；参数、封装格式、内存清理和失败尝试限制须在私密模块实现前通过安全设计评审并记录。
5. **安装包体积验证**：需要在选定 OCR 模型、导出库和加密库后进行真实构建测量。

- 导出：格式面板、朋友圈竖图快速导出、首次选择保存位置、导出成功反馈、导出失败反馈和错误详情。

### 13.2 视觉审阅结论

- 普通页面和隐私页面使用同一套间距、文字和按钮基础规范。
- 普通页面使用 A「极简留白」；隐私页面使用文字主导的石墨/冷灰/深蓝灰小面积状态色风格。
- 全局按钮使用深石墨主按钮、石墨描边次按钮和灰蓝文字操作；蓝灰不作为大面积背景或普通主按钮底色。危险操作使用灰度层级、明确文案和二次确认，不使用红色。
- 黄色从最终视觉系统中移除；完成状态与成功状态使用低饱和蓝色。
- 预览中自动出现的“统计”“我的”等未确认导航不属于产品范围。
- 预览中普通搜索结果曾自动出现“加密笔记”条目；这是预览生成误差，正式实现必须彻底隔离普通搜索与加密模块。
- 预览中的风景图、背景图和大锁/钥匙插画不属于 V1 隐私页要求；自定义壁纸属于后续版本。

### 13.3 实现中必须通过的技术验证门槛

1. 开始 OCR 实现前，验证本地模型的许可证、中文/英文混排效果、安装包体积和批量处理限制。
2. 开始私密模块实现前，完成数据密钥参数、封装格式、内存清理和失败尝试限制的安全设计评审；加密待办仍须与普通待办隔离。
3. 发布前通过真实构建确认安装包不超过 300 MB，并在低内存设备上验证 A4 600 DPI 分页导出。
4. 首页自适应规则已确定；实现验收仍须覆盖窄屏、大字体、横向空间和深色模式，不把规则确定误记为设备验收通过。

### 13.4 最终审阅结论

- **页面范围已覆盖**：首页、编辑、皮肤、图片与 OCR、待办、私密模块、备份恢复、导入、导出、导出记录、回收站、设置、数据与存储、批量操作、首次启动隐私说明、空状态和无结果状态均已有设计方向或流程预览。
- **视觉基线已冻结**：石墨黑、白色和冷灰为主；低饱和蓝灰只用于小面积进度、选中和状态提示；不使用大面积蓝色、黄色、红色，也不加入没有功能意义的宣传副标题。
- **隐私边界已冻结**：普通搜索、普通待办、普通导出记录和系统最近任务预览均不得暴露私密模块存在或内容；私密内容、附件、OCR 索引、待办和导出记录只在解锁后的私密范围内可见。
- **内容与导出规则已冻结**：每条笔记独立保存；一级文件夹；图片为独立内容块且保持比例；首行自动标题并保留在正文；A4 PDF、600 DPI 分页 PNG、长图和 1080 × 1080/1080 × 1350 社交图片；Markdown 使用 ZIP 交付图片资源。
- **V1 不纳入范围**：自定义壁纸、复杂多级文件夹、多文件夹归属、小米笔记专用迁移、广泛 Markdown 扩展兼容、文件级密码导出和云同步。
- **分阶段技术门槛**：OCR 与私密模块须分别在对应模块实现前完成模型/安全验证；安装包体积和低内存 A4 600 DPI 分页导出须在发布验收前通过。当前实现进度以实现计划为准。
